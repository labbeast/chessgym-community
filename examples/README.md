# Starter examples

The PGNs, teaching comments and descriptive text in [starter.json](starter.json) were written for ChessGym with AI assistance. They are original educational examples, not attributed historical games or excerpts from a book, course or commercial collection. Comments are in French and English. The lines illustrate basic ideas and do not claim a theoretical advantage.

| Example | Enabled activity | Requirement |
| --- | --- | --- |
| Italian opening | Repertoire and spaced review | No engine needed for ordinary move review |
| Develop your pieces | Guess the Move, classic | Stockfish for scoring attempts |
| Centre, development and castling | Reading with variations and bookmark | No engine needed |

Choose **Add the examples** in **Settings → Installation** or in the empty library. Installation is local and makes no network request. Each example occupies its own editable study base. Repeating the action restores missing example bases and leaves existing bases, names, settings, annotations and progress unchanged. The older four-example pack, if already present, remains untouched. Deleting an example is the same explicit operation as deleting any personal base.

The pack manifest is versioned in account preferences and is included in personal backups together with its study bases. It identifies bases by both ID and creation timestamp, so a later personal base reusing a deleted ID is never mistaken for an example.
